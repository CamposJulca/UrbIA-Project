# presentacion_cli

Este módulo contiene la interfaz de línea de comandos (CLI) de UrbIA para usuarios finales.

## Comandos útiles

- Ejecutar CLI:
  ```
  mvn clean compile exec:java
  ```

- Compilar como JAR:
  ```
  mvn package
  java -jar target/presentacion-cli.jar
  ```

## Requisitos
- Java 17+
- Maven
- Archivo `.env` configurado
